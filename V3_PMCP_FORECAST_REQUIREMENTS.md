# V3.5 — PMCP Care Forecast and Calendar Requirements

## Purpose
Turn selected PMCP care items into a forward-looking 12-month care forecast with an optional 24-month outlook. This is not a DIY instruction sheet. It is a homeowner-facing care roadmap and a THA operating plan: what THA/PASS can service directly, what THA coordinates with a qualified trade, and what the homeowner may choose to handle independently.

## Required fields for every forecasted item
- Care item and trade/domain
- Cadence: monthly, quarterly, seasonal, semiannual, annual, every 24 months, condition-based, or as needed
- Next due date or practical window
- Basis: homeowner-reported history, THA-observed date, THA-established baseline, or catalog-only recommendation
- Delivery path: THA/PASS direct service, THA-coordinated trade, homeowner option, or confirm applicability
- Planning status: not scheduled, planned, scheduled, completed, deferred, or verify/establish baseline

## Core rules
- Default to a client-facing 12-month view; offer an optional 24-month outlook.
- Show repeated events when cadence requires them. A 3–6 month filter task can appear several times between annual furnace services.
- Support alternating/nonannual work. Chimney service can appear in year two when appropriate.
- Air-duct cleaning stays condition-based; never make it a routine annual requirement.
- Forecasted care remains separate from repair findings, PMR counts, priorities, and rail colors.
- Intake, Field Prep, and HTC can provide evidence, dates, applicability, or refined cadence. They never automatically create a repair, approve work, or select a PMCP item.
- PMCP Builder remains the full internal catalog. The homeowner receives only the selected care plan with timing, rationale, responsibility, and service path.

## Example patterns
- Furnace filter: every 3–6 months, with several forecast windows inside a year; THA/PASS or homeowner option.
- Furnace service: annual, normally fall; THA coordinates qualified HVAC service.
- Dryer vent: annual or use/access-based; THA/PASS or qualified vent provider.
- Gutter/downspout review: spring and fall; THA/PASS, with escalation when warranted.
- Chimney/fireplace service: 12–24 months when applicable; THA coordinates chimney trade.
- Air-duct cleaning: condition-based review only; HVAC trade when evidence warrants it.

## Build order
1. Complete V3.1–V3.3 so source data is trustworthy.
2. Finalize catalog cadence and evidence rules.
3. Generate forecast events only from selected PMCP items.
4. Build 12-/24-month calendar/timeline views for the internal Builder and homeowner-facing care plan.
5. Add reminders/automation only after Drive/client record workflow and consent rules are designed and tested.

## Acceptance checks
- A clean house receives a useful care forecast without false repair findings.
- A 3–6 month item creates multiple planned windows in a 12-month view.
- A 24-month item can appear in the extended outlook without cluttering the default year.
- Every event shows why it matters, its evidence/basis, timing, service path, and responsible resource.
